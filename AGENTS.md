# Mission Trainer — правила для агентів

Браузерна 2D покрокова стратегія для NASA Space Apps 2026 (челендж «Build a Junior Astronaut Mission Trainer»).
Гравець 30 солів керує місячною базою, балансуючи енергію, життєзабезпечення, їжу й радіацію; головна складність — пережити місячну ніч.

## Команди
- `npm run dev` — локальний сервер розробки
- `npm run build` — перевірка типів і збірка в `dist/`
- `npm test` — тести (Vitest)

## Мапа папок і власники
| Папка | Що всередині | Власник |
|---|---|---|
| `src/shared/types.ts` | Контракт між рушієм та інтерфейсом | спільний (лише за домовленістю) |
| `src/sim/` | Рушій: `newGame(seed, level)`, `reduce`, `forecast` + тести | рушій/контент |
| `src/content/` | Дані: модулі, події (`events.ts`), місії (`levels.ts`), усі числа балансу (`balance.ts`) | рушій/контент |
| `src/ui/` | React-компоненти інтерфейсу: `screens/` (екрани), `hud/`, `map/`, `panels/`, `overlays/` | інтерфейс |
| `src/mocks/` | Готові `GameState` і тимчасовий демо-рушій для верстки без справжнього рушія | інтерфейс |
| `src/App.tsx` | Точка збирання інтерфейсу | інтерфейс |
| `public/sprites/` | Спрайти | інтерфейс |
| `blender/` | Вихідники 3D/рендерів спрайтів | інтерфейс |

## Правила
- **НЕ змінювати `src/shared/types.ts`** без прямого прохання людини. Це контракт між двома людьми.
- `src/sim` — лише чисті функції, без React і без DOM. Випадковість — лише через seed (власний ГПВЧ у стані/аргументах), **`Math.random` напряму не використовувати**.
- Інтерфейс сам нічого не рахує: стан змінюється лише через `reduce(state, action)`, прогнози — лише через `forecast(state)`.
- Інтерфейс звертається до рушія лише через `src/ui/engine.ts`. Поки `reduce` у `src/sim` кидає `not implemented`, там автоматично вмикається демо-рушій `src/mocks/demoEngine.ts` (спрощені правила, НЕ баланс гри). Щойно справжній рушій готовий — демо вимикається саме, нічого перемикати не треба.
- Не додавати нових залежностей без питання людині.
- Працювати лише у своїх папках (див. таблицю).
- Гілки: `ui/...` для інтерфейсу, `sim/...` для рушія й контенту. У `main` напряму не пушити — лише через pull request.
- **Мова:** усе, що не англійською, — українською: тексти гри, коментарі в коді, назви тестів, повідомлення комітів, описи PR, документація. Російську не використовувати.
