# Mission Trainer

Покрокова стратегія про місячну базу: протримайся 30 солів і переживи місячну ніч. NASA Space Apps 2026 — «Build a Junior Astronaut Mission Trainer».

**Грати:** https://kosaultra-stack.github.io/mission-trainer/

## Запуск локально

```bash
npm install
npm run dev
```

Тести: `npm test`. Збірка: `npm run build`, перегляд збірки: `npm run preview`.

Правила для розробників та ШІ-агентів — у [AGENTS.md](AGENTS.md).
