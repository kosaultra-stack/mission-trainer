# Mission Trainer

Пошаговая стратегия про лунную базу: продержись 30 солов и переживи лунную ночь. NASA Space Apps 2026 — «Build a Junior Astronaut Mission Trainer».

**Играть:** https://<username>.github.io/mission-trainer/

## Запуск локально

```bash
npm install
npm run dev
```

Тесты: `npm test`. Сборка: `npm run build`, просмотр сборки: `npm run preview`.

Правила для разработчиков и ИИ-агентов — в [AGENTS.md](AGENTS.md).
